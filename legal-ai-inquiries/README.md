# Legal AI inquiries

This directory is the public, non-confidential intake surface for Brazilian Legal AI Evaluation & Red-Team Services.

To start an inquiry without using email:

1. Fork this repository.
2. Add a new Markdown file in this directory named `your-organisation-YYYY-MM-DD.md`.
3. Use the template in [`../LEGAL_AI_INQUIRIES.md`](../LEGAL_AI_INQUIRIES.md).
4. Open a pull request back to this repository.

Do not include privileged, confidential, proprietary, client-identifying, health, financial, credential, or other sensitive information in a public pull request. Initial scope should be limited to project type, approximate volume, jurisdiction/language relevance, target timing and the desired paid engagement tier.

A private business channel can be agreed after fit is established.
