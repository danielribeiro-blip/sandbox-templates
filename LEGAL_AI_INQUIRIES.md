# Legal AI Project Inquiries

This repository does not use email as the intake channel for these engagements.

For a **non-confidential initial inquiry**, use a GitHub pull request:

1. Fork this repository.
2. Add a Markdown file under `legal-ai-inquiries/` named with your organisation/project and date, for example `legal-ai-inquiries/example-2026-09-08.md`.
3. Include only public scoping information using the template below.
4. Open a pull request against this repository.

Do **not** include privileged, confidential, proprietary, personal, health, financial, credential, or client-identifying information in a public pull request.

## Public scoping template

```md
# Legal AI inquiry

Organization / project: [public name or description]

Need:
- [ ] Legal AI output evaluation
- [ ] Brazilian-law / Portuguese-language review
- [ ] Citation / authority verification
- [ ] Legal dataset QA
- [ ] Benchmark / rubric design
- [ ] Red-team / workflow review
- [ ] Fractional Legal AI SME

Public problem statement:
[Describe the problem without confidential information.]

Approximate volume:
[Outputs, documents, benchmark items, or workflow stages.]

Desired delivery window:
[Date / range.]

Preferred next private channel:
[Provide a business contact method only if you are comfortable posting it publicly.]
```

A private channel can be agreed after the public, non-confidential scoping note. No confidential material should be posted to this repository.
